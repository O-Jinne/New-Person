# 🧑 새사람 프로젝트 — 운동 트래커 앱

Day 1~4 루틴을 선택하고, 각 운동을 체크하고, 실제로 친 무게/세트를 기록하고,
필요하면 커스텀 운동도 추가할 수 있는 개인 웹앱이야.

## 로컬에서 미리보기

`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 확인 가능해.
(단, 이 상태에서는 아직 인터넷 어디서든 접속은 안 되고 이 컴퓨터에서만 보여)

---

## GitHub Pages로 무료 배포하기 (단계별)

### 1단계: GitHub 계정 만들기
- https://github.com 접속 → Sign up
- 이미 계정 있으면 스킵

### 2단계: 새 저장소(repository) 만들기
1. GitHub 로그인 후 우측 상단 `+` → `New repository`
2. Repository name: `monster-project` (원하는 이름 아무거나 OK)
3. `Public` 선택 (Pages 무료 사용하려면 Public이어야 함)
4. `Create repository` 클릭

### 3단계: 파일 업로드
1. 방금 만든 저장소 페이지에서 `uploading an existing file` 링크 클릭
2. 이 폴더 안의 3개 파일을 전부 끌어다 놓기:
   - `index.html`
   - `style.css`
   - `app.js`
3. 하단에 `Commit changes` 클릭

### 4단계: GitHub Pages 활성화
1. 저장소 상단 메뉴에서 `Settings` 클릭
2. 왼쪽 메뉴에서 `Pages` 클릭
3. `Source`를 `Deploy from a branch`로 설정
4. `Branch`를 `main` (또는 `master`), 폴더는 `/ (root)` 선택
5. `Save` 클릭

### 5단계: 완료!
- 몇 분 기다리면 상단에 초록색 박스로 URL이 뜸
- 형식: `https://[본인깃허브아이디].github.io/monster-project/`

## 📱 아이폰 홈 화면에 앱처럼 설치하기

배포된 URL을 그냥 북마크만 해두면 매번 사파리 주소창을 거쳐야 해서 불편해. 아래대로 하면 다른 앱들처럼 홈 화면 아이콘 눌러서 바로 켤 수 있어.

### 처음 설치할 때

1. **아이폰 사파리**(꼭 Safari여야 함, 크롬 등 다른 브라우저는 "홈 화면에 추가" 기능이 안 뜨거나 다르게 동작함)로 배포된 URL 접속
2. 화면 하단(또는 상단) **공유 버튼**(네모에서 위쪽 화살표 나가는 아이콘 □↑) 탭
3. 아래로 스크롤해서 **"홈 화면에 추가"** 선택
4. 이름 확인하고(기본값 "새사람 프로젝트") 우측 상단 **"추가"** 탭
5. 홈 화면에 아이콘이 생기면 완료 — 이제 이 아이콘으로 열면 사파리 주소창 없이 진짜 앱처럼 전체화면으로 실행돼

### 업데이트했는데 옛날 화면 그대로 보일 때

이 앱을 업데이트해서 GitHub에 새로 올려도, 아이폰이 예전 버전을 캐시(임시저장)해두고 있으면 홈 화면 아이콘 눌러도 안 바뀐 것처럼 보일 수 있어. 이럴 때:

1. 홈 화면 아이콘 길게 눌러서 **"앱 제거"**
2. 설정 → **Safari** → 아래로 스크롤 → **"고급"** → **"웹 사이트 데이터"**
3. 검색창에 `github.io` 입력 → 나오는 항목 왼쪽으로 밀어서 **삭제**
4. 사파리로 원래 URL 다시 접속해서 새 버전 잘 뜨는지 확인
5. 다시 공유 버튼 → **"홈 화면에 추가"**로 재설치

## ⚠️ 중요: 데이터 저장 방식

지금 버전은 **브라우저 localStorage**를 사용해.
즉, 데이터가 **이 기기의 이 브라우저에만** 저장돼.

- 아이폰 사파리에서 저장한 기록은 아이폰 사파리에서만 보임
- 크롬으로 열면 기록이 안 보임 (다른 저장소라서)
- 사파리 데이터/방문기록 삭제하면 기록도 같이 삭제됨
- 홈 화면에 추가한 아이콘도 결국 사파리 저장공간을 그대로 쓰는 거라, 위 "웹 사이트 데이터 삭제"를 하면 기록도 같이 날아감 (업데이트할 때 주의!)

**여러 기기에서 동기화하고 싶으면** (예: 아이폰 + 컴퓨터 둘 다) 나중에
Firebase 같은 클라우드 데이터베이스를 연결해야 해. 이건 다음 단계로 확장 가능!

**데이터가 걱정되면**: 프로필 화면에 있는 "데이터 내보내기" 버튼으로 주기적으로 백업 파일(JSON)을 받아두면 안전해.
